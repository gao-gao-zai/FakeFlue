# 旧设置页显示适配（R23、R25）

## 实现范围

旧 `SettingsPageScaffold` 的列表页，以及图片、视频表盘的独立设置页，统一接入 `SettingsPageFrame`。

- 内容视口使用已保存的安全区宽高，居中并裁剪滚动内容。安全区变化立即作用于已打开页面。
- 背景铺满窗口，右滑返回也可从安全区外的留边发起。
- 系统安全边距只补足超出已校准留边的部分，避免重复累加。
- 旧列表继续保留圆屏弦宽缩放、首项居中、滚动位置、搜索定位、旋钮与单一滚动层。
- 图片、视频页的右滑、系统返回和返回按钮共用原有提交回调，退出前处理待提交的修改。
- 安全区和 DPI 校准页保留各自的预览与保存、取消行为。

## 验证场景

`LegacySettingsJourneyTest` 在 API 30 模拟器执行以下五项真实界面测试：

1. 设置页打开期间保存 75% 宽、70% 高的安全区，检查实际可访问滚动视口边界，重新打开后再次检查。
2. 切为圆屏并保存最小的 55% × 55% 安全区，检查视口并进入、退出备份页面。
3. 从工具进入备份和导入页，通过右滑逐级返回，检查父页面滚动位置保留。
4. 在默认 Apple 风格下对原设置滑条执行横向拖动，检查数值确实变化且没有误返回，再检查纵向滚动和右滑返回。
5. 分别打开图片、视频表盘设置，测量各自窗口基线，检查安全区边界和右滑返回。

既有 `ReleaseUiSmokeTest` 的备份页面导航改用真实右滑，覆盖导入页、导出页、多级返回和父页面位置恢复，并继续执行原有首次引导、DPI 保存与外部强制停止后的恢复检查。

本地全量单元测试已完成：2229 项、0 失败、0 错误，5 项因缺少本地样本跳过。Debug APK、仪器测试 APK 和独立 Release 验收 APK 均构建通过。

[PR #17](https://github.com/gao-gao-zai/FakeFlue/pull/17) 已合并为 `b4049aa`。该阶段的 [CI](https://github.com/gao-gao-zai/FakeFlue/actions/runs/44988253695) 执行 Debug 13 项、R8 Release 首轮 3 项与恢复 1 项，均通过；当时滑条回归使用 Material 3。随后 [PR #18](https://github.com/gao-gao-zai/FakeFlue/pull/18) 补齐默认控件语义并恢复默认 Apple 风格测试，最终组合的 [CI](https://github.com/gao-gao-zai/FakeFlue/actions/runs/44995141399) 执行 Debug 18 项、0 失败、0 跳过，包含上述 5 项；R8 Release 3＋1 项也通过。[main 合并后检查](https://github.com/gao-gao-zai/FakeFlue/actions/runs/44996335333) 已通过，应用基线为 `f20d343`。
